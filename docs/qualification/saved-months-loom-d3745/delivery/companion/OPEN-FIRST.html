See which months and currencies occur in one saved Household ledger—including months with budgets and no transactions.

Read-only saved-file command

1. Open the example

Extract the whole ZIP. With Node.js installed, open a terminal in the folder containing this page and run:

node tools/household-months.mjs --ledger example/household.json

No npm install or build step. This exact runtime was received on Linux with Node 24.19.0.

2. Select your saved ledger

Replace the quoted path with your existing Household Ledger JSON file:

node tools/household-months.mjs --ledger "/absolute/path/to/ledger.json"

The command prints JSON and leaves the input unchanged. It counts saved rows without adding missing months, converting currencies or totaling amounts.

If saving stdout, use a different, new destination. Never redirect it into the input ledger.

Source, limits and qualification

The CLI/helper are published in Household PR 40 at 4d7b36118967a2076fdf642f99da462a8bb862c1. The emitted validator and synthetic example retain their exact qualified PR8 bytes. This companion does not imply main-branch adoption or an installed MCP service.

Recorded keys and occurrence counts are not balances or account completeness. summary_supported checks the existing summary's year range only; native currency/budget rules still apply. Inputs are limited to 16 MiB and 100,000 combined rows.
