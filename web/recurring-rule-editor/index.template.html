3. Generate one month explicitly


Save the rule file, then use the existing recurring-plan command with a selected month and a new output path. This page does not run it.


node dist/src/household-recurring-plan.js --rules household-recurring-rules.json --month 2026-11 --out november-plan.json


Keep the command's complete receipt. It records the normalized currency, which must be supplied when opening the plan with the expense preview. The plan file itself contains no currency.


Saving rules checks their format, not a month's generated total or number of occurrences. The generator can still refuse a month that exceeds its limits.


No server, network connection, automatic storage or automatic download. Reloading closes unsaved work. Save and keep your files explicitly.
